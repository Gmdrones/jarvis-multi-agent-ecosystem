# Remote Desktop Commander MCP

Remote desktop access must be explicitly authorized. Install Node.js LTS, then consult the current [Desktop Commander documentation](https://desktopcommander.app/) for pairing and client-specific MCP configuration. A typical remote launcher command is `npx @wonderwhy-er/desktop-commander@latest remote`, but verify the current package and arguments with its official documentation before use. Never commit pairing URLs, session IDs, device identifiers, or access tokens. Keep command execution behind explicit approval.

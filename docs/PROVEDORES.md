# Model Providers

**Ollama:** Install from https://ollama.com/, run `ollama pull llama3.2`, then test with `ollama run llama3.2`. The current dashboard does not call Ollama automatically.

**Gemini:** Obtain an API key from Google's official developer portal and store it in a local environment variable, not in Git.

**OpenAI:** Obtain an API key from https://platform.openai.com/ and store it outside version control. ChatGPT subscriptions do not automatically include API credits.

The community MVP has no production provider router; integrations remain planned.

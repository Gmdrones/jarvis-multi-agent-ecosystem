# Native factory executor

Runs inside the existing Maestri commercial console, using its native CLI context. Research and creation stay in existing agents; original captures, canonical qualification, dependency initialization, builds, browser QA and guarded preview deployment use bounded JSON requests.

Read EXECUTOR_CONTRACT.md before submitting jobs. Each request needs a unique ID. No arbitrary shell jobs, new paid resources or outreach. Official Instagram embeds preserve attribution; public availability does not grant download/rehosting rights.

The first new supervised cycle was validated on 2026-11-03: https://jarvis-digital.pages.dev/ismerim-barbearia/ . Public QA passed 1440/768/390, including both videos progressing. Existing Studio962 remained HTTP200. This is evidence of one completed cycle, not a two-minute SLA or completion of20 projects.

The runtime records source hashes and rejects CAPTCHA, mismatched executed queries, stale builds/reviews, private URL paths and unapproved public files. It preserves previous release slugs. Independent visual/factual review remains required. A research dispatcher resumes batches when Hunter is ready and queues are drained, until the existing20-site goal.

This configuration targets the current Windows/Maestri installation and requires the PC and Maestri to remain running. It does not replace source verification or guarantee third-party Instagram uptime.
